# Contributing

Thanks for helping keep this list accurate.

## What belongs here

This repository documents **GitHub's own profile achievements and highlight badges** —
their artwork, their tier thresholds and how they are earned.

## What does not belong here

Please do not open issues or pull requests for:

- **Star-for-star, follow-for-follow or badge-swap requests.** Coordinated activity to
  farm achievements is against the [GitHub Acceptable Use Policies](https://docs.github.com/site-policy/acceptable-use-policies/github-acceptable-use-policies)
  and can get your account restricted.
- **Promoting your own project or tool.** Use [Discussions](https://github.com/drknzz/GitHub-Achievements/discussions) instead.
- **Test issues and test pull requests.** Practise on your own repository.
- **Adding unrelated files** (scripts, workflows, HTML pages, personal files).

## Before you open an issue

1. Search [open](https://github.com/drknzz/GitHub-Achievements/issues) and
   [closed](https://github.com/drknzz/GitHub-Achievements/issues?q=is%3Aissue+is%3Aclosed) issues —
   most badge questions have already been answered.
2. Check the README's **Badges no longer earnable** section. Several badges that people
   still ask about have been retired by GitHub.

## Reporting a badge change

Achievement criteria change without notice, so a claim is only actionable with a source.
Please include a link to one of:

- [GitHub Docs](https://docs.github.com/en/account-and-profile/reference/profile-reference)
- The [GitHub Changelog](https://github.blog/changelog/)
- A [GitHub Community discussion](https://github.com/orgs/community/discussions) with a staff reply

A screenshot of your own profile shows that a badge exists, but not what earns it or what
the tier thresholds are, so please pair it with a source.

## Pull requests

- One change per pull request, and say in the description what you changed and why.
- Link the source that supports the change.
- Keep the existing table structure and the `/Media/...` local image paths — do not swap
  them for `github.githubassets.com` URLs or third-party shields.
- Update the "last verified" date in the README if you re-checked the criteria.
